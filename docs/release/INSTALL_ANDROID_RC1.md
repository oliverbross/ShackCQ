# Install Android RC1

Use `ShackCQ-Android-arm64-v0.1.0-rc.1.apk` for the protected arm64 device. Existing installations must be backed up and upgraded only with `adb install -r`; never uninstall or clear data. Verify package UID, schema, retained QSO/config counts, launch, and crash logs. The AAB is a distribution artifact, not a directly installable package.
