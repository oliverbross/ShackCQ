# ShackCQ 0.1.0 RC1

ShackCQ is a GPLv3 radio operating workspace for Android, iPhone/iPad, macOS, Windows, Linux, and a standalone station service.

This RC consolidates the accepted native mobile and desktop lineages, closes full Linux GUI parity, adds secure remote clients to Compose, SwiftUI, and Qt/QML, adds adaptive Opus RX with PCM fallback and optional bounded raw I/Q, and adds Android MIDI/HID control-surface mapping with an immutable Global Stop path.

All published binaries are release-candidate artifacts. Desktop and Apple archives are unsigned; the Apple XCArchive is not an installable IPA. No store deployment, signing, notarisation, RF transmission, remote PTT/TUNE, or rotator movement is claimed. See the platform install guides and POST_RC1_LIVE_ACCEPTANCE.md.
