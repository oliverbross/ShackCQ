# Portable catalogue provider matrix

| Programme | State/contract | ShackCQ behavior |
|---|---|---|
| POTA | Existing reviewed runtime authority | Existing private cache and search |
| SOTA | Existing reviewed catalogue/cluster authority | Private summit cache, native detail and exact-host secure browser |
| IOTA | AVAILABLE after official JSON download | Bounded conditional download, schema validation, atomic last-good, digest/date, groups/subgroups/islands/DXCC and offline search; provider bounds are retained but no centroid is invented |
| WWBOTA | PROVIDER_BLOCKED | Candidate CSV endpoint exists, but automated cache/redistribution terms were not established; lawful user import only |
| WWFF live | AVAILABLE under existing reviewed Spotline/agenda contract | Live activity only |
| WWFF directory | LICENCE_BLOCKED or USER_IMPORT | No scrape/download/bundle. Oliver Bross OM0RX may select an authorised CSV; source date/digest remain private |
| Castles | PROVIDER_BLOCKED | Official external source plus lawful user import; no reviewed licensed coordinate feed |
| Lighthouses | PROVIDER_BLOCKED | Official ARLHS external source plus lawful user import; no reviewed licensed bulk API |

Unavailable is never displayed as an empty result. The registry always reports status, source, update time, row count, cache/import state, digest and reason.
